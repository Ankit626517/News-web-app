# 📰 News Website

Welcome to the **News Website** project! 🌍  
A modern, responsive platform to stay updated with the latest headlines, categorized by topics and sourced using APIs. 🧠💡

---

## 🚀 Features

- 🗞️ Live news updates from top sources  
- 📂 Categorized sections (Technology, Sports, Entertainment, etc.)  
- 🔍 Search functionality to find specific news  
- 📱 Fully responsive design for mobile and desktop  
- 🌙 Dark mode support (optional)

---

## 🛠️ Tech Stack

- ⚛️ **React.js** – Frontend framework  
- 🎨 **Tailwind CSS** – For UI styling  
- 🔗 **News API** – For fetching latest articles  
- 🌐 **Axios** – For API calls  
- 🔧 **React Router** – Page routing and navigation
